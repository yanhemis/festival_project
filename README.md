# festiver_project

로그인, 회원가입 페이지 만들고, 테스트하고 싶어서 firebase랑 데이터베이스 연결해서 로그인 시도해보려고 합니다. main_creen.dart는 로그인 성공하면 넘어가는 메인페이지여서 테스트하려고 임시로 만들기만 해놨습니다. 현재는 클라이언트에서만 테스트해서 계속 버튼을 누르면 무조건 에러 메시지가 출력됩니다. 회원가입 절차에 이메인 인증이나 전화번호 인증을 추가하고 싶어서 firebase로 일단 시도하려고 하고, 아마 firebase를 사용하면 구글이나 애플로 로그인하는 기능도 간단하게 테스트할 수 있을 것 같습니다.


로그인 페이지에서 메인 페이지로 넘어가는 로직 추가
되면 데이터베이스로 회원가입 데이터 넘겨서 저장 로직 추가
되면 cognito 연결해서 이메일 인증 추가
되면 로그인 테스트
